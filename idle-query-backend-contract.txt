空闲插座查询后端约定（最小裁剪版）

1. 前端请求原则
- 前端只发楼栋标识，不带页面上的全部站点列表。
- 共享冷却：四个楼栋共用同一个 15 秒查询冷却，任意一个楼栋刚查询过，其他三个楼栋也要一起禁用。

2. 请求格式
- 接口：POST /api/idle/query
- Content-Type: application/json
- 必须携带认证头：Authorization: Bearer <token>
- token 与登录接口保持一致，不要省略。
- 请求体最小格式：
  {"area":"20栋"}
- area 取值：
  - 20栋
  - 19栋
  - 图书馆
  - 南门

3. 返回原则
- 后端不要重新拼一套新变量名。
- 直接在原始返回上做最小裁剪即可。
- 只保留前端渲染需要的字段，裁掉 balance、devInfo、rechargeData、texts、tips 这类无关内容。
- 如果后端本来就是原始对象，前端也能兼容；如果方便，建议只返回裁剪后的轻量 JSON。
- 一次请求建议一次性返回整批站点的完整状态，不要按单个插座分多次推送。
- 前端拿到结果后会整体渲染，不需要等一个插座一个插座地补齐。

4. 正常返回最小格式
- 推荐返回按站点分组的最小格式：
  {
    "msg": "解析完毕",
    "sites": [
      {
        "siteNo": 1,
        "siteName": "1号站",
        "state": 0,
        "availableCount": 12,
        "sockets": [
          {
            "socketNo": 1,
            "state": 0,
            "countdown": null,
            "endTime": "未知"
          },
          {
            "socketNo": 2,
            "state": 1,
            "countdown": 3720,
            "endTime": "33698691"
          }
        ]
      },
      {
        "siteNo": 2,
        "siteName": "2号站",
        "state": 1,
        "availableCount": 4,
        "sockets": []
      }
    ],
    "products": []
  }
- state 含义：
  - 0 表示空闲
  - 1 表示充电中
- countdown 优先返回，单位秒。
- endTime 作为备用字段，前端会尝试换算。
- siteNo / siteName 用来对应具体站点，前端按它们分组展示。
- siteName 示例建议写成“1号站”“2号站”这种站点名，不要写成南侧、北侧这种方位词。
- 如果后端暂时只能返回扁平列表，也必须给每个条目带 siteNo 或 siteName。

5. 扁平兼容格式
- 如果暂时不方便返回 sites，也可以返回：
  {
    "msg": "解析完毕",
    "products": [
      {
        "siteNo": 1,
        "siteName": "1号站",
        "sid": 1,
        "state": 0,
        "countdown": null,
        "endTime": "未知"
      }
    ]
  }
- 这种情况下每条记录仍然必须带 siteNo 或 siteName，不然前端无法知道它属于哪个站点。

6. 离线返回最小格式
- 如果设备离线，建议后端直接返回：
  {
    "normal": -10,
    "msg": "设备离线,请更换其他设备",
    "sites": [],
    "products": []
  }
- 前端看到 normal=-10 时，会直接显示离线提示，不再渲染插座状态。
- 这种情况不用再塞一堆站点数据。

7. 前端兼容规则
- 如果返回 sites，前端会按站点号/站点名分组后渲染。
- 如果返回 products，前端会把它当作插座级列表直接渲染，但每条记录仍应带 siteNo 或 siteName。
- 如果 state 为 0，显示“无状态”，并用空闲色。
- 如果 state 为 1，显示“充电中”。
- 如果 countdown 有值，前端会显示成“X时Y分Z秒”，并自动递减。
- 如果没有 countdown，但有 endTime，前端会尝试换算。
- 如果两个时间字段都没有，前端只显示“充电中”。
- 如果 normal = -10，前端显示“设备离线，请更换其他设备”。

8. 离线和错误区分
- 服务没响应：前端显示“服务器未响应”。
- 返回了但格式不对：前端显示“数据格式不对”。
- 设备离线：前端显示“设备离线，请更换其他设备”。

9. 冷却规则
- 查询按钮冷却时间固定 15 秒。
- 不管查询的是哪个楼栋，四个按钮都共享同一把冷却锁。
- 冷却期间按钮显示剩余秒数，且全部不可点击。
