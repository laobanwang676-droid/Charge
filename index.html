说明

为什么不能直接跳过验证
页面只是前端展示。真正决定能不能充电的是后端接口，它会检查服务器会话里是否已经完成手机号验证。没有验证令牌，直接调用充电接口也会被拒绝。
你现在会得到什么
一个独立的 Python 网页后端 + 一个单页 HTML 界面。适合先在本机跑通，再决定是否挂到 cpolar 或 GitHub Pages。
运行地址
默认是 http://127.0.0.1:8080。后面如果你要暴露公网，就把这个本地端口交给 cpolar 去转发。
